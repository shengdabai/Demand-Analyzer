# 需求分析工具

一个智能的需求分析工具，帮助创业者和产品经理分析需求是否满足"高频、广泛、刚需"三要素，并提供优化建议。

当前评分来自本地关键词规则和用户填写的市场规模，不代表经过验证的市场需求、付费意愿或投资依据。`examples.md` 中的历史示例分数不是当前算法的回归基准。

## 🎯 功能特色

### 核心分析维度
- **📈 高频性分析**：评估需求的使用频率和重复性
- **🌐 广泛性分析**：分析需求的用户群体覆盖范围
- **🎯 刚需性分析**：判断需求是否解决用户的实际问题

### 智能功能
- **关键词智能识别**：自动识别需求描述中的关键特征
- **综合评分系统**：100分制综合评估市场需求潜力
- **个性化优化建议**：基于分析结果提供具体改进方案
- **实时反馈**：即时显示分析结果和改进建议

## 📋 使用指南

### 本地检查

需要 Node.js 22 或更新版本，无需安装依赖：

```bash
npm test
node --check script.js
```

测试覆盖各维度进度条上限、目标用户去空与去重，以及市场规模只影响广度的规则；实际浏览器布局仍需单独检查。

### 基本使用流程
1. **输入需求信息**
   - 填写需求标题（简洁明了）
   - 详细描述需求内容
   - 指定目标用户群体
   - 选择预计市场规模

2. **查看分析结果**
   - 总体评分（0-100分）
   - 三个维度的详细得分
   - 智能评估和建议
   - 具体优化建议

### 评分标准
- **80-100分**：优秀，建议优先投入
- **60-79分**：良好，有提升空间
- **40-59分**：一般，需要改进
- **0-39分**：需改进，建议重新审视

### 关键词分析说明

#### 高频性关键词
- **日常频率**：每天、日常、每日、频繁、经常
- **周期频率**：每周、周常、定期、周期性
- **场景频率**：通勤、工作、学习、生活、用餐

#### 广泛性关键词
- **普适性**：所有人、全民、通用、普适、大众
- **人群覆盖**：学生、上班族、职场、家庭、老人
- **地域覆盖**：全国、全球、国际、城市、农村

#### 刚需性关键词
- **基础需求**：必需、必要、必须、基础、核心
- **问题解决**：痛点、困难、问题、挑战、障碍
- **情感需求**：焦虑、压力、担忧、恐惧、渴望

## 🔧 自定义配置

### 添加新关键词
在 `script.js` 中的 `keywords` 对象中添加：

```javascript
keywords: {
    highFrequency: {
        // 添加新的频率关键词
        custom: ['自定义关键词1', '自定义关键词2']
    }
}
```

### 调整评分权重
在对应的分析方法中修改评分计算逻辑。

## 📈 使用案例

### 案例1：在线学习平台
- **需求描述**：为学生和职场人士提供在线学习课程
- **分析结果**：
  - 高频性：25分（学习需求相对高频）
  - 广泛性：28分（覆盖学生和职场人士）
  - 刚需性：30分（技能提升是刚需）
  - **总分：83分** - 优秀

### 案例2：智能提醒应用
- **需求描述**：帮助用户管理日常待办事项和提醒
- **分析结果**：
  - 高频性：30分（日常使用频率高）
  - 广泛性：22分（适用人群相对广泛）
  - 刚需性：25分（时间管理是刚需）
  - **总分：77分** - 良好
